# 🎨 Palette de Couleurs - Portfolio Guillaume KERE

## Nouveau Design : Noir & Orange

### Couleurs Principales

#### 🟠 Orange (Couleur d'accent)
- **Orange Principal** : `#ff6b35` - Utilisé pour les boutons, liens, et éléments interactifs
- **Orange Foncé** : `#e55a2b` - Utilisé pour les effets hover et les variantes
- **Orange Clair** : `#ff8856` - Utilisé pour les dégradés et effets de lumière

#### ⚫ Noir & Gris
- **Noir Principal** : `#1a1a1a` - Utilisé pour le texte et les fonds sombres
- **Gris Foncé** : `#2d2d2d` - Utilisé pour les sections et variations
- **Gris Moyen** : `#666666` - Utilisé pour le texte secondaire

#### ⚪ Blanc & Gris Clair
- **Blanc** : `#ffffff` - Fonds de cartes et texte sur fond sombre
- **Gris Très Clair** : `#f5f5f5` - Fonds de sections alternées

### Application des Couleurs

#### Navigation
- Fond transparent qui devient noir (rgba(26, 26, 26, 0.95)) au scroll
- Bordure orange en bas lors du scroll
- Liens blancs avec soulignement orange au survol

#### Hero Section
- Fond noir avec dégradé subtil
- Overlay orange avec faible opacité
- Boutons avec fond orange et effets au survol

#### Sections
- Alternance entre fond blanc et gris très clair
- Titres en noir profond
- Accents orange pour les icônes et éléments interactifs

#### Timeline (Expériences)
- Ligne orange reliant les expériences
- Badges de dates avec fond orange
- Cartes blanches avec bordure gauche orange

#### Cartes & Éléments Interactifs
- Cartes blanches avec ombres
- Icônes dans des cercles orange
- Effets de survol avec transformation et ombre accentuée

#### Footer
- Fond noir (#1a1a1a)
- Texte blanc
- Icônes sociales avec fond semi-transparent et effet orange au survol

### Effets et Animations
- **Dégradés** : Orange principal vers orange foncé
- **Ombres** : Noires avec différentes opacités
- **Hover** : Transformations avec changement de couleur vers orange plus vif
- **Bordures actives** : Orange pour indiquer les éléments actifs

### Accessibilité
- Contraste texte noir sur blanc : ✅ Excellent (21:1)
- Contraste texte blanc sur orange : ✅ Bon (4.7:1)
- Contraste texte blanc sur noir : ✅ Excellent (21:1)

### Variables CSS

Toutes les couleurs sont définies dans `assets/css/style.css` :

```css
:root {
    --primary-color: #ff6b35;      /* Orange principal */
    --primary-dark: #e55a2b;       /* Orange foncé */
    --primary-light: #ff8856;      /* Orange clair */
    --secondary-color: #1a1a1a;    /* Noir */
    --text-dark: #1a1a1a;          /* Texte foncé */
    --text-light: #666666;         /* Texte clair */
    --bg-dark: #2d2d2d;            /* Fond sombre */
}
```
