# Portfolio Professionnel - Guillaume KERE

Portfolio personnel professionnel développé avec HTML5, CSS3 (Bootstrap 5), et JavaScript vanilla.

## 📋 Description

Ce portfolio présente mon parcours professionnel, mes compétences et mes réalisations dans le domaine de la communication, du journalisme et de la création de contenu audiovisuel.

## 🚀 Fonctionnalités

- **Design Responsive** : Optimisé pour tous les appareils (desktop, tablette, mobile)
- **Navigation fluide** : Menu de navigation fixe avec indicateur de section active
- **Animations** : Animations d'apparition au scroll (AOS library)
- **Sections complètes** :
  - Hero section avec présentation
  - À propos
  - Expérience professionnelle (timeline)
  - Formation académique
  - Compétences techniques et professionnelles
  - Langues
  - Réalisations (à compléter)
  - Formulaire de contact
  - Références
- **Performance optimisée** : Code léger et rapide
- **Accessibilité** : Respect des standards WCAG avec ARIA labels

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Styles modernes avec variables CSS
- **Bootstrap 5.3.2** : Framework CSS responsive
- **JavaScript ES6+** : Interactivité et animations
- **Font Awesome 6.5.1** : Icônes
- **AOS 2.3.1** : Animations au scroll

## 🖼️ Configuration de l'image de profil

1. Placez votre photo de profil professionnelle dans le dossier `assets/images/`
2. Nommez-la `profile.jpg`
3. Spécifications recommandées :
   - Format : JPG, PNG ou WebP
   - Dimensions : Minimum 800x800px (format carré)
   - Taille : Moins de 500KB
   - Photo portrait professionnelle avec bon éclairage

## 🌐 Déploiement

### Option 1 : GitHub Pages
1. Créez un repository GitHub
2. Poussez votre code
3. Activez GitHub Pages dans les settings du repository
4. Votre site sera accessible à `https://votre-username.github.io/PortefolioKERE`

### Option 2 : Netlify
1. Créez un compte sur [Netlify](https://netlify.com)
2. Glissez-déposez le dossier du projet
3. Votre site sera en ligne en quelques secondes

### Option 3 : Vercel
1. Créez un compte sur [Vercel](https://vercel.com)
2. Importez le repository GitHub
3. Déploiement automatique à chaque commit

## ✏️ Personnalisation

### Modifier les couleurs
Éditez les variables CSS dans `assets/css/style.css` :

```css
:root {
    --primary-color: #2563eb;
    --primary-dark: #1e40af;
    --primary-light: #3b82f6;
    /* ... autres variables ... */
}
```

### Ajouter vos réalisations
La section réalisations est actuellement en placeholder. Pour ajouter vos projets, modifiez la section `#portfolio` dans `index.html`.

### Configurer le formulaire de contact
Le formulaire est actuellement en mode simulation. Pour l'intégrer avec un service d'envoi d'emails :

- **FormSpree** : Ajoutez `action="https://formspree.io/f/YOUR_FORM_ID"` au formulaire
- **EmailJS** : Intégrez le SDK EmailJS dans `script.js`
- **Backend personnalisé** : Créez votre propre API

### Ajouter vos réseaux sociaux
Modifiez les liens des icônes sociales dans les sections Hero et Footer :

```html
<a href="https://linkedin.com/in/votre-profil" class="social-link">
    <i class="fab fa-linkedin"></i>
</a>
```

## 📱 Responsive Design

- Tablette : 576px - 991px
- Desktop : > 992px
